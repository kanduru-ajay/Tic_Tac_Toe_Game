🎮 Tic Tac Toe Game Using Python

📌 Project Description

The Tic Tac Toe Game is a simple interactive Python-based game designed for two players.

The game is played on a 3×3 grid where two players take turns marking their positions with X and O.

The program checks the winning conditions after every move and declares the winner when a player successfully places three matching symbols in a horizontal, vertical, or diagonal row.

If all nine positions are filled without a winner, the game declares a draw.

Two-player gameplay.

Validates user input.
Displays the winner at the end of the game.
🎮 Game Rules
The game consists of a 3×3 grid.
Player 1 uses X, and Player 2 uses O.
Players take turns selecting positions from 1 to 9.
A player wins by placing three matching symbols in a row, column, or diagonal.
If all positions are filled without a winner, the game ends in a draw.
